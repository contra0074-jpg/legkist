# Легкість — меню на тиждень під бюджет

Застосунок для Android та iPhone. Він ставить 11 запитань: магазин, родина, прийоми їжі, дні, техніка, харчування, алергії, бюджет. Потім складає меню, рецепти та список покупок.

GitHub безкоштовно збирає з цієї папки дві речі:

- **Android** — файл `Legkist.apk`, який встановлюється на телефон;
- **iPhone** — веб-версію за посиланням. Її додають на головний екран, і вона відкривається як звичайний застосунок, також без інтернету.

## Як запустити (один раз, ~15 хвилин)

1. **Створіть репозиторій.** Зареєструйтесь на github.com і натисніть **New repository**. Назва — `legkist`, тип — **Public** (безкоштовна публікація сторінки працює лише для публічних), далі **Create repository**.
2. **Завантажте файли.** Розпакуйте архів. На сторінці репозиторію натисніть **uploading an existing file** і перетягніть **вміст** папки `legkost-app`: `www`, `assets`, `.github`, `package.json`, `package-lock.json`, `capacitor.config.json` та інші. Потім **Commit changes**.
   - Папка `.github` прихована. На Mac її показує `Cmd + Shift + .`, у Windows — «Вигляд → Приховані елементи».
   - Якщо перетягнути її не вдається: **Add file → Create new file**, у назві введіть `.github/workflows/build.yml` і вставте вміст цього файлу з архіву.
3. **Увімкніть сторінку.** **Settings → Pages → Source → GitHub Actions**.
4. **Запустіть збирання.** Вкладка **Actions → «Зібрати застосунок» → Run workflow**. Збирання триває 5–8 хвилин. Далі воно запускатиметься само після кожної зміни файлів.

## Як встановити

**Android:** на телефоні відкрийте репозиторій → **Releases → «Легкість для Android»** → завантажте `Legkist.apk` і відкрийте файл. Телефон попросить дозволити встановлення з цього джерела — дозвольте.

**iPhone:** у Safari відкрийте `https://ВАШ-ЛОГІН.github.io/legkist/` → кнопка «Поділитися» → **«На початковий екран»**.

## Повноцінний застосунок для iPhone і магазини застосунків

- **App Store:** потрібні Mac з Xcode та Apple Developer Program ($99 на рік). На Mac: `npm install`, `npm run ios`, `npx cap open ios` → підписати своїм акаунтом → Archive → завантажити.
- **Google Play:** потрібен акаунт розробника ($25 один раз) і підписаний файл `.aab` замість `.apk`.

## Ціни

Ціни лежать у файлі `www/index.html`, у блоці `const I={...}`.

- **Базові ціни** — середні споживчі ціни Держстату за жовтень 2026 (index.minfin.com.ua, оновлено 15.11.2026).
- **Позиції, яких Держстат не публікує** (помідори, банани, йогурт тощо), — оцінка. У рядку такої позиції стоїть `,1`, а в застосунку вона позначена «ціна орієнтовна».
- **Поправки мереж** (`const STORES`) — за порівнянням цін на хліб, гречку, яйця та олію в АТБ, Сільпо, Novus і Ашан від 10.06.2026: АТБ 0,93; Сільпо 1,02; Novus 1,01; Ашан 1,05.

Щоб оновити ціни, змініть числа в цьому файлі й дату в `PRICE_DATE`. Застосунок перезбереться сам.
